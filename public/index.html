WHITE-BOX INPUTS

        
Bring your source into the picture.

        

          Import a local source folder or clone a public HTTPS Git repository.
          Code is read, not executed. No API key is needed.
        

        
        

          
        

        

          Preserves imported source files and classifies dependency manifests,
          configuration, schema/migrations, authorization code, routes, tests,
          CI/CD, and Git history. Dependency/cache folders and symbolic links
          are excluded. All exclusions and size limits appear in the inventory.
          Source and history can contain real credentials and are stored
          locally.
